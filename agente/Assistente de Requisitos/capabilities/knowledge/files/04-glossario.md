# Clube Aurora · Glossário

> Produto fictício.

| Termo | Significado |
| --- | --- |
| **Participante** | Cliente cadastrado no Clube Aurora (RN-01). |
| **Ponto pendente** | Ponto de uma compra que ainda está no prazo de arrependimento e não pode ser resgatado (RN-04). |
| **Ponto disponível** | Ponto liberado, que pode ser usado em um resgate. |
| **Resgate** | Uso dos pontos como desconto em uma compra (RN-07 a RN-10). |
| **Extrato** | Lista de pontos ganhos, resgatados, estornados e expirados, com as datas. |
| **Nível** | Classificação do participante (Bronze, Prata ou Ouro) conforme os pontos acumulados em 12 meses (RN-11). |
| **Bônus de nível** | Percentual extra de pontos para os níveis Prata e Ouro (RN-12). |
| **Estorno** | Retirada dos pontos de uma compra cancelada ou devolvida (RN-05). |
| **Expiração** | Perda dos pontos não usados depois de 12 meses (RN-06). |
